# BasiDraft — контракт импорта из БАЗИС

Этот документ фиксирует обязательное правило рабочего процесса и имеет приоритет над исследовательскими выводами, сделанными по полностью оформленным тестовым чертежам.

## Что приходит из БАЗИС

В штатном рабочем процессе BasiDraft должен рассчитывать, что из БАЗИСа приходит **геометрическая заготовка**:

- виды;
- разрезы;
- узлы;
- контуры и внутренняя геометрия модели;
- при наличии — структура блоков / слоёв / служебные метаданные, которые помогают распознать вид.

## Что НЕ является входными данными

BasiDraft не должен зависеть от наличия в DXF/LDW:

- размеров БАЗИСа;
- размерных стрелок и выносных линий БАЗИСа;
- текста оформления;
- подписей видов;
- сносок и позиций;
- пользовательских пояснений;
- оформительской штриховки как готового конечного объекта.

В реальной целевой работе этих объектов может не быть вообще.

Если они случайно присутствуют в импортируемом файле, BasiDraft должен считать их **чужими / legacy annotations** и не использовать как обязательную основу своей логики. Пользователь должен иметь возможность отбросить их при импорте.

## Всё оформление создаётся в BasiDraft

BasiDraft самостоятельно создаёт и хранит:

- размеры;
- размерные цепочки;
- собственные стрелки / окончания размеров;
- выносные линии;
- размеры до центров;
- надписи и подписи видов;
- сноски;
- позиции деталей на взрыве;
- обозначения разрезов и узлов;
- собственную штриховку;
- рамку / основную надпись и нумерацию листов, если они входят в проект BasiDraft.

Эти объекты являются нативными объектами проекта BasiDraft и должны иметь собственные привязки, стили, историю и статус актуальности.

## Следствие для архитектуры

Основной pipeline:

`BAZIS geometry -> DXF/QCAD import -> фильтрация чужого оформления -> raw geometry -> нормализация -> logical view -> semantic features -> BasiDraft annotations`

Распознавание видов и определение масштаба **не должно требовать импортированных размеров или текста БАЗИСа**.

Приоритет определения масштаба:

1. надёжная метаинформация формата / блока, если она реально присутствует и подтверждена тестами;
2. надёжная метаинформация LDW-sidecar, если она декодирована без предположений;
3. явно сохранённый масштаб ранее созданного BasiDraft-вида при обновлении;
4. подтверждение / выбор масштаба пользователем.

Импортированные DIMENSION/TEXT из полностью оформленных контрольных DXF допустимо использовать только как **диагностический материал при исследовании формата**, но не как обязательную производственную зависимость.

## Главное правило

**БАЗИС даёт геометрию. BasiDraft делает чертёж.**
